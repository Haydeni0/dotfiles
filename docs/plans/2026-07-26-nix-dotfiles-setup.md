# Nix dotfiles setup - Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a reproducible Nix/home-manager dotfiles setup on this remote (Ubuntu 22.04, CoreWeave Slurm node, no root) that installs and manages the user's terminal tools and dotfiles from one git repo (`~/gitrepos/dotfiles`), modeled on the reference video's config.

**Architecture:** Rootless userspace Nix (`nix-portable`) lives in `$HOME/.nix-portable` (no `/nix`, no daemon, no root). home-manager standalone builds the user profile at `~/.nix-profile/` and writes dotfiles via two mechanisms: (1) `programs.<x>` Nix expressions (immutable, in the Nix store) for zsh/starship/tmux/git/btop/zoxide/rclone, and (2) `mkOutOfStoreSymlink` for nvim config (edit-in-place, in the repo). The repo `~/gitrepos/dotfiles` is symlinked to `~/.dotfiles` for stable out-of-store paths.

**Tech Stack:** Nix flakes, home-manager (standalone, release-26.05), nixpkgs 26.05, nix-portable (rootless Nix), herdr (flake input `github:ogulcancelik/herdr/v0.7.5`).

**Spec:** `docs/specs/2026-07-26-nix-dotfiles-design.md` (read for full context).

## Global Constraints

- **No root, no `/nix`, no daemon.** All Nix state in `$HOME` via nix-portable. Per AGENTS.md: never use `sudo`, never edit system files, never pipe remote content into shell (`curl ... | sh`).
- **No secrets in the flake.** The repo is on public GitHub (`Haydeni0/dotfiles`). No API keys, no credentials, no `~/.config/rclone/rclone.conf` managed by HM. The plaintext `AGENTS_ANTHROPIC_API_KEY` in `.bashrc` is deleted (not ported).
- **No `git commit` or `git push`** unless the user explicitly asks. Per AGENTS.md, commit/push need explicit sentinels (`COMMIT_AUTHORISED`/`PUSH_AUTHORISED`) which are NOT present. `git add` is allowed for staging.
- **Binary files never go in the git repo.** Backups of text configs go to `~/dotfiles-backup-20260726/` (outside repo); binaries in `~/.local/bin` are moved aside, not archived.
- **home-manager manages ONLY zsh.** `~/.bashrc` and `~/.profile` stay manual (the bash→`exec zsh -l`→tmux bridge must keep working unchanged).
- **No `chsh`.** Login shell stays bash; zsh launched via the existing `exec zsh -l` bridge in `.bashrc`.
- **SSH untouched.** `~/.ssh/` and the SSH agent setup in `.bashrc` are not managed by Nix.
- **Mac deferred.** Only `hosts/remote.nix` for now; `hosts/mac.nix` added later by a separate session.
- **Repo:** `~/gitrepos/dotfiles` (GitHub `Haydeni0/dotfiles`, already cloned, currently empty working tree `Fresh start with nothing`).
- **Paths:** `home.username = "hayden.dorahy"`, `home.homeDirectory = "/mnt/home/hayden.dorahy"`, `home.stateVersion = "24.11"`.
- **Don't touch conda dirs yet** - the `rm -rf ~/.conda ~/.mamba` step is user-run, not auto-run (flag the `aau_token*` files first).

Replace the entire contents of `~/.bashrc` with this slimmed version (keeps the bash→zsh→tmux bridge, ssh-agent, AWS_PROFILE, envman; drops dead code, aliases, prompt, history, completions, the API key, EDITOR):

```bash
# ~/.bashrc: slimmed - bash launches zsh, so only env + bridge matter here.

# If not running interactively, don't do anything
case $- in
    *i*) ;;
      *) return;;
esac

# SSH agent - adds all private keys
if [ -z "$SSH_AUTH_SOCK" ]; then
    eval "$(ssh-agent -s)" > /dev/null
    find ~/.ssh -maxdepth 1 -type f -name "*.pub" -exec basename {} .pub \; | while read key; do
        ssh-add ~/.ssh/"$key" 2>/dev/null
    done
fi

# uv env (kept until Nix sessionPath replaces it; harmless alongside)
. "$HOME/.local/bin/env" 2>/dev/null

# envman
[ -s "$HOME/.config/envman/load.sh" ] && source "$HOME/.config/envman/load.sh"

export AWS_PROFILE=coreweave

# Launch zsh if interactive, not in a remote container, not in a cursor agent
if command -v zsh &> /dev/null && \
   [[ $- == *i* ]] && \
   [[ -z "${REMOTE_CONTAINERS_SOCKETS}" ]] && \
   [[ -z "${CURSOR_AGENT}" ]]; then
    exec zsh -l
else
    # Bash-side tmux fallback (when zsh isn't available)
    if [ -n "$PS1" ] && \
      [ -z "$TMUX" ] && \
      [ "$TERM_PROGRAM" != "vscode" ] && \
      command -v tmux &>/dev/null; then
      exec tmux new-session -A -s main
    fi
fi
```

Note: EDITOR is removed here - home-manager sets `EDITOR=nvim` via `home.sessionVariables` in the managed zsh. The `alias btop='bpytop'`, `alias cat='~/.local/bin/bat -p'`, `alias cc`, `alias oc`, `alias ll`/`la`/`l`, `alias alert` all move to the managed zsh (Task 6).

## Task 3: Write `flake.nix`

**Files:**
- Create: `~/gitrepos/dotfiles/flake.nix`

**Interfaces:**
- Consumes: `home/default.nix` (Task 9), `hosts/remote.nix` (Task 8), herdr flake input.
- Produces: `homeConfigurations."hayden@remote"` that other tasks will reference via `home-manager switch --flake .#hayden@remote`.

- [ ] **Step 1: Write `flake.nix`**

Create `~/gitrepos/dotfiles/flake.nix`:

```nix
{
  description = "dotfiles - home-manager setup (remote-first)";

  inputs = {
    nixpkgs.url = "github:NixOS/nixpkgs/nixos-26.05";
    home-manager.url = "github:nix-community/home-manager/release-26.05";
    home-manager.inputs.nixpkgs.follows = "nixpkgs";

    # herdr is not in nixpkgs at v0.7.5; use its own flake
    herdr.url = "github:ogulcancelik/herdr/v0.7.5";
  };

  outputs = inputs@{ self, nixpkgs, home-manager, herdr, ... }:
    let
      system = "x86_64-linux";
      pkgs = import nixpkgs { inherit system; };
      herdrPkg = herdr.packages.${system}.default;
    in
    {
      homeConfigurations."hayden@remote" = home-manager.lib.homeManagerConfiguration {
        inherit pkgs;
        extraSpecialArgs = { inherit herdrPkg; };
        modules = [
          ./home/default.nix
          ./hosts/remote.nix
        ];
      };
    };
}
```

Note: using `nixos-26.05` (Linux release branch) + `home-manager/release-26.05` - the tested pair, matches what the reference video uses (with the darwin variant swapped for Linux). Avoids HM/nixpkgs drift. `home.stateVersion = "24.11"` stays (valid enum on HM release-26.05, one-time migration flag - don't change it). Package version note: uv 0.11.21 (vs 0.11.28 on unstable) and zoxide 0.9.9 (vs 0.10.0 on unstable) - both slightly behind unstable but functional; btop/gdu/rclone/rsync match unstable.

- [ ] **Step 1: Write `home/shell.nix`** (zsh + starship + aliases)

```nix
{ config, pkgs, ... }:

{
  programs.zsh = {
    enable = true;
    autosuggestion.enable = true;
    syntaxHighlighting.enable = true;
    initContent = ''
      # Start tmux (ported verbatim from the user's .zshrc)
      if [ -n "$PS1" ] && \
        [ -z "$TMUX" ] && \
        [ "$TERM_PROGRAM" != "vscode" ] && \
        command -v tmux &>/dev/null; then
        exec tmux new-session -A -s main
      fi

      # Cursor sends Ctrl+Left/Ctrl+Right as escape sequences ending in D/C.
      # Bind them to zle word movement so Ctrl+Left/Ctrl+Right move by word.
      bindkey $'\e[1;3D' backward-word
      bindkey $'\e[1;3C' forward-word

      # compinit
      fpath+=~/.zfunc
      autoload -Uz compinit
      compinit -u

      # envman (defensive - kept from the user's setup)
      [ -s "$HOME/.config/envman/load.sh" ] && source "$HOME/.config/envman/load.sh"
    '';
    shellAliases = {
      # user's aliases (kept - not the video's cc/co)
      cc = "~/.local/bin/local-claude";
      oc = "~/.local/bin/local-opencode";
      ll = "ls -alF";
      la = "ls -A";
      l = "ls -CF";
      cat = "${pkgs.bat}/bin/bat -p";
      btop = "${pkgs.btop}/bin/btop";  # real btop, not the bpytop alias
      # video's non-conflicting aliases
      ".." = "cd ..";
      add = "git add .";
      push = "git push";
      pull = "git pull";
      m = "git switch main";
    };
  };

  programs.starship = {
    enable = true;
    settings = {
      add_newline = false;
      format = "$directory$git_branch$git_status$cmd_duration$line_break$character";
      character = {
        success_symbol = "[❯](purple)";
        error_symbol = "[❯](red)";
      };
      cmd_duration.format = "[$duration]($style) ";
    };
  };

  home.sessionVariables = {
    EDITOR = "nvim";
  };
}
```

Note: `cat` alias uses the Nix `bat` (`${pkgs.bat}/bin/bat`) - resolves to the store path, not `~/.local/bin/bat`. Same for `btop`. This means the alias works even if `~/.local/bin` is off PATH.

## Task 9: Apply with `home-manager switch` (the big step)

**Files:**

- Modifies: `~/.gitconfig` (home-manager takes ownership)

- Consumes: the locked flake from Task 8.
- Produces: a fully applied home-manager profile on this box.

**Why this is one task:** the `switch` is atomic - either it all applies or it rolls back. Splitting it would leave half-applied state.
